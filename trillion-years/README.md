# What If You Lived for 1 Trillion Years?

A 10-minute (10:00.000) narrated 3D video, 1280×720 at 30 fps, with subtitles,
a running "your age" counter and an original procedural soundtrack.

**Video:** [`What_If_You_Lived_1_Trillion_Years.mp4`](What_If_You_Lived_1_Trillion_Years.mp4)

Everything is generated by code. There is no stock footage, no samples and no
external art.

| Layer | How it's made |
| --- | --- |
| Visuals | 14 real-time Three.js scenes (particles, custom GLSL shaders, a restricted N-body galaxy collision), rendered frame by frame in headless Chromium |
| Narration | Script in [`script.json`](script.json), voiced offline with the Kokoro TTS neural voice model |
| Music & sound | Ambient pads, drone, bells, heartbeat and effects synthesized with numpy ([`audio/music.py`](audio/music.py)), ducked under the voice |
| Assembly | ffmpeg (H.264 + AAC) |

## Rebuilding

```bash
./build.sh
```

`build.sh` runs four steps:

1. `audio/tts.py` voices each line, then solves the pauses so the timeline is exactly 600 s. It writes `build/narration.wav` and `build/timeline.json`.
2. `audio/music.py` writes the score and mixes it with the narration into `build/soundtrack.wav`.
3. `render/render.mjs` renders 18,000 JPEG frames. Each scene reads its narration cue times from the timeline, so the visuals stay in sync with the voice.
4. ffmpeg encodes the MP4.

Kokoro model files go in `./models` (see the comment in `build.sh`).

To preview single frames without a full render:

```bash
cd render && node render.mjs --times 12,215,560 --out /tmp/preview
```

## Facts used

The narration follows mainstream scientific estimates. Key figures:

- **Age and scale.** The universe is 13.8 billion years old, so 1 trillion years is about 72× that. Counting to a trillion at one number per second takes about 31,700 years.
- **Betelgeuse.** It is expected to go supernova within roughly the next 100,000 years, and would be visible in daylight.
- **Pangaea Ultima.** The continents are projected to reassemble in about 250 million years.
- **Galactic year.** One orbit of the Milky Way takes about 230 million years, at about 230 km/s (more than 800,000 km/h).
- **A brightening Sun.** The Sun gets about 10% brighter per billion years. This leads to the loss of most plant life (about 600 million years) and the loss of the oceans (about 1 billion years).
- **Andromeda.** A merger with the Milky Way is likely within the next several billion years.
- **The Sun's death.** The red-giant phase starts in about 5 billion years and reaches more than 200× the Sun's current radius. Then comes a planetary nebula and a white dwarf.
- **The cosmic horizon.** Galaxies beyond the Local Group pass beyond it in about 100 billion years.
- **The Local Group.** It merges into a single galaxy in about 450 billion years.
- **One trillion years.** Star formation is winding down, and the cosmic microwave background is no longer detectable.
- **Red dwarfs.** They keep shining for trillions of years.
